# Assets Cocineritos IGI de Verano

Rama separada, solo con imágenes. No forma parte del sitio (la rama `main` no se tocó).

Contiene las 4 gráficas de la campaña y sus capas recortadas (fondo, banderines, globos, logo, titular, sellos y pie),
publicadas para que HeyGen pueda leerlas por link directo al armar las animaciones.

Se puede borrar esta rama cuando los videos estén terminados.
